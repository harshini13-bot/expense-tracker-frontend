🎨 Frontend - Expense Tracker UI

A Streamlit-based frontend for visualizing and managing expenses.

⚙️ Tech Stack
Streamlit (UI)
Requests (API calls)
Pandas (Data handling)
Matplotlib (Visualization)
📌 Features
Add expenses
View expenses in table
Update and delete expenses
Search & filter expenses
Sort expenses
Visual analytics dashboard
Category-wise spending chart
📁 Project Structure
frontend/
│── app.py
│── utils.py (optional)
⚙️ Setup Instructions
1️⃣ Install dependencies
pip install streamlit requests pandas matplotlib
2️⃣ Run frontend
streamlit run app.py
🔗 Backend Connection

Make sure backend is running:

http://127.0.0.1:8000

In frontend code:

server_loc = "http://127.0.0.1:8000"
📊 Features UI Supports
Expense dashboard
Category charts
Clean table view
Search & filters
🌐 Frontend runs at:
http://localhost:8501
